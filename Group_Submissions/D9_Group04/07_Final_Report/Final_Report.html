1. Problem Statement

A 4-bit game score (0–15) is set on switches S3–S0. When START is pressed, the score is sampled and classified. A Moore FSM keeps the result on one indicator LED until ACK is pressed, and then returns to IDLE. RESET (synchronous, active-high) returns the system to IDLE at any time. Modification H1 replaces the three base categories with four:

Score (Dec)Score[3:0]CategoryLED
0 – 40000 – 0100LOWGreen
5 – 80101 – 1000MEDIUMYellow
9 – 121001 – 1100HIGHRed
13 – 151101 – 1111EXCELLENTBlue

2. Requirements and Assumptions

  • Moore FSM, 5 states (IDLE, LOW, MEDIUM, HIGH, EXCELLENT), 3-bit binary encoding.
  • IDLE → category state on START; category state → IDLE on ACK; RESET forces IDLE.
  • The 4-bit input register loads the switches on every clock while in IDLE and holds its value in every other state.
  • START and switch changes are ignored outside IDLE; ACK has no effect in IDLE.
  • Unused codes 101, 110, 111 return to IDLE on the next clock.
  • All 16 inputs are valid (unsigned score), so no error state is needed.

3. Architecture

The datapath contains the input register and the combinational range decoder. The controller is a Moore FSM: a 3-bit state register, next-state logic and output logic. Distinctive feature: on the board the RGB LED lights in the category colour in addition to the four category LEDs.

Range decoder (comparators)

Three 4-bit unsigned comparators compare the registered score with the constants 4, 8 and 12:

ComparatorConditionOutput
C1Score > 4GT4
C2Score > 8GT8
C3Score > 12GT12

L = GT4' (0–4)   M = GT4·GT8' (5–8)   H = GT8·GT12' (9–12)   E = GT12 (13–15)

5. Logisim Implementation

Logisim Evolution 5.0.0, file 02_FSM_Logisim/Game_Score_Categorizer.circ. The circuit uses 7 D flip-flops (4 for the input register, 3 for the state), three 4-bit unsigned Comparators and basic gates, arranged left to right as inputs, inverters, input register, range decoder, next-state logic, state register, output logic and LEDs. Each register bit uses D = IDLE·Si + IDLE'·Ri. In the range decoder a splitter joins R3–R0 into the 4-bit bus SCORE, which is compared with constants 4, 8 and 12. All 16 scores were checked with START, hold, ACK and RESET: 16/16 pass.

6. Verilog Implementation

Coding style: parameter state codes, case on Moore_State with begin/end per state and if/else transitions, Moore outputs assigned in every state (no latches), synchronous reset, default to IDLE.

Game_Score_Categorizer.v

`timescale 1ns/1ps
module Game_Score_Categorizer (Score, START, ACK, Clock, Reset,
                               LED_LOW, LED_MEDIUM, LED_HIGH, LED_EXCELLENT);
  input [3:0] Score;
  input START, ACK, Clock, Reset;
  output LED_LOW, LED_MEDIUM, LED_HIGH, LED_EXCELLENT;
  reg LED_LOW, LED_MEDIUM, LED_HIGH, LED_EXCELLENT;

  parameter IDLE = 3'b000, LOW = 3'b001, MEDIUM = 3'b010, HIGH = 3'b011, EXCELLENT = 3'b100;
  reg [2:0] Moore_State;
  reg [3:0] Score_Reg;

  wire Is_Low, Is_Medium, Is_High, Is_Excellent;

  assign Is_Low       = (Score_Reg <= 4'd4);
  assign Is_Medium    = (Score_Reg >= 4'd5)  & (Score_Reg <= 4'd8);
  assign Is_High      = (Score_Reg >= 4'd9)  & (Score_Reg <= 4'd12);
  assign Is_Excellent = (Score_Reg >= 4'd13);

  always
    @ (posedge Clock)
      if (Reset)
        Score_Reg <= 4'b0000;
      else if (Moore_State == IDLE)
        Score_Reg <= Score;
      else
        Score_Reg <= Score_Reg;

  always
    @ (posedge Clock)
      if (Reset)
        Moore_State <= IDLE;
      else
        case (Moore_State)
          IDLE :
            begin
              if (START)
                begin
                  if (Is_Low)
                    Moore_State <= LOW;
                  else if (Is_Medium)
                    Moore_State <= MEDIUM;
                  else if (Is_High)
                    Moore_State <= HIGH;
                  else
                    Moore_State <= EXCELLENT;
                end
              else
                Moore_State <= IDLE;
            end

          LOW :
            begin
              if (ACK)
                Moore_State <= IDLE;
              else
                Moore_State <= LOW;
            end

          MEDIUM :
            begin
              if (ACK)
                Moore_State <= IDLE;
              else
                Moore_State <= MEDIUM;
            end

          HIGH :
            begin
              if (ACK)
                Moore_State <= IDLE;
              else
                Moore_State <= HIGH;
            end

          EXCELLENT :
            begin
              if (ACK)
                Moore_State <= IDLE;
              else
                Moore_State <= EXCELLENT;
            end

          default :
            begin
              Moore_State <= IDLE;
            end
        endcase

  always
    @ (Moore_State)
      case (Moore_State)
        IDLE :
          begin
            LED_LOW = 0;
            LED_MEDIUM = 0;
            LED_HIGH = 0;
            LED_EXCELLENT = 0;
          end

        LOW :
          begin
            LED_LOW = 1;
            LED_MEDIUM = 0;
            LED_HIGH = 0;
            LED_EXCELLENT = 0;
          end

        MEDIUM :
          begin
            LED_LOW = 0;
            LED_MEDIUM = 1;
            LED_HIGH = 0;
            LED_EXCELLENT = 0;
          end

        HIGH :
          begin
            LED_LOW = 0;
            LED_MEDIUM = 0;
            LED_HIGH = 1;
            LED_EXCELLENT = 0;
          end

        EXCELLENT :
          begin
            LED_LOW = 0;
            LED_MEDIUM = 0;
            LED_HIGH = 0;
            LED_EXCELLENT = 1;
          end

        default :
          begin
            LED_LOW = 0;
            LED_MEDIUM = 0;
            LED_HIGH = 0;
            LED_EXCELLENT = 0;
          end
      endcase

endmodule

Game_Score_Top.v (Boolean board)

`timescale 1ns/1ps
module Game_Score_Top (clk, sw, btn, led, RGB0, RGB1);
  input clk;
  input [15:0] sw;
  input [3:0] btn;
  output [15:0] led;
  output [2:0] RGB0;
  output [2:0] RGB1;

  parameter DIV_BIT = 19;

  reg [DIV_BIT:0] Div_Count;
  wire Slow_Clock;
  wire LED_LOW, LED_MEDIUM, LED_HIGH, LED_EXCELLENT;

  initial Div_Count = 0;

  always
    @ (posedge clk)
      Div_Count <= Div_Count + 1;

  assign Slow_Clock = Div_Count[DIV_BIT];

  Game_Score_Categorizer FSM (.Score(sw[3:0]), .START(btn[0]), .ACK(btn[1]),
                              .Clock(Slow_Clock), .Reset(btn[2]),
                              .LED_LOW(LED_LOW), .LED_MEDIUM(LED_MEDIUM),
                              .LED_HIGH(LED_HIGH), .LED_EXCELLENT(LED_EXCELLENT));

  assign led[0] = LED_LOW;
  assign led[1] = LED_MEDIUM;
  assign led[2] = LED_HIGH;
  assign led[3] = LED_EXCELLENT;
  assign led[15:4] = 12'b000000000000;

  assign RGB0[0] = LED_MEDIUM | LED_HIGH;
  assign RGB0[1] = LED_LOW | LED_MEDIUM;
  assign RGB0[2] = LED_EXCELLENT;
  assign RGB1 = 3'b000;
endmodule

11. Conclusion

The four-category Game Score Categorizer (H1) was designed as a Moore FSM with a registered datapath and a comparator-based range decoder. The Logisim implementation was verified for all 16 scores, every state, reset, START/ACK sequencing and boundary values. Verilog simulation and FPGA hardware results: [pending]. Limitations: one score per transaction. Future work: 7-segment display of the score, category counters (H4), CHANGE detection (H5).
