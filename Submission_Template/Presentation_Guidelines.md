# Presentation Guidelines ( Only 4 Slides excluding title slide)

Cover:
**Slide 1** : Ttile , College Logo, University Logo, Group Name, Team name and Roll No. class, Department + college  name and year. 
**Slide 2:** 
  1. Problem statement, objectives and requirements.
  2. Proposed architecture and distinctive features.
**Slide 3:**
  1. combinational design, FSM/state table and Logisim implementation, where applicable.
  2. Verilog RTL architecture and design decisions.
**Slide 4:**
  1. Testbench, test cases and simulation results. Utilization Results( Screenshots from report :LUTS, FF, CArry 4, RAM etc.)
  2. FPGA board, implementation flow and hardware demonstration.
**Slide 5:**
  1. Expected-versus-observed results, challenges and corrections.
  2. Conclusion, limitations and future improvements.
  3. Individual contribution of each group member.

All four members should be ready to answer technical questions.
